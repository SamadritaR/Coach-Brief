    Baseline first

    Nights 1 to 3 set the user’s own baseline. Every change is measured against them, not against an average person.

    Last seven nights

    Each brief reads the week since the last check in, so the coach sees what moved since they last spoke.

    No source, no flag

    A line appears only when specific nights support it, and it names them.

    The window matters

    Return risk is judged against the 30 day refund window, so coaches spend time where a user might leave.
